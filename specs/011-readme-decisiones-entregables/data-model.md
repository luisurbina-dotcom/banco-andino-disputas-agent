# Data Model: entregables

| Entidad | Contenido | Validación |
|---|---|---|
| README.md | requisitos, arranque, demo, e2e, plugin, estructura, enlaces | comandos ejecutados desde un clon limpio (quickstart Q1) |
| DECISIONES.md | necesidad 1–11 → mecanismo, ubicación, razón | 11 necesidades presentes, ≤ 1.000 palabras, rutas existentes |
| Guion de caso (`demo/cN_*.txt`) | un mensaje del cliente por línea | produce los indicadores del caso en el chat |
| Paquete (`.zip`) | clon con `.git` | sin nombres prohibidos, credenciales ni datos con forma real; ≤ 50 MB |
